# Домашние рецепты — учебный Vue-проект

Небольшое приложение для домашней работы №5. Это не замена основного сайта: страницы `index.html`, `login.html` и JSON Server остаются в папке `hw_5` рядом с этой папкой.

## Запуск

Команды нужно выполнять из папки `vue-homework-5`.

```powershell
npm install
npm start
```

После запуска откройте http://localhost:8080.

Остановить сервер: в том же терминале нажмите `Ctrl+C`.

Проверка сборки:

```powershell
npm run build
```

Готовые файлы появятся в папке `dist`.
