## Задание

Добавить к сайту вторую тему. Нужны либо светлая и тёмная темы с опорой на настройки пользователя, либо две свои темы с переключателем. Сделаны оба механизма сразу: система задаёт тему при первом заходе, кнопка позволяет выбрать вручную.

## Что сделано

Цвета вынесены в CSS-переменные. Общий файл `assets/css/styles.css` больше не хранит палитру, он только использует `var(--bg)`, `var(--ink)`, `var(--card)` и остальные имена.

Две темы:

- `assets/css/themes/light.css` — прежняя тетрадь: кремовый фон, терракотовые кнопки, тёмно-зелёные ссылки;
- `assets/css/themes/dark.css` — тёмный фон `#241f1b`, светлый текст, те же имена переменных.

В файлах темы также заданы переменные Bootstrap: `--bs-body-bg`, `--bs-body-color`, `--bs-border-color`. Поэтому формы, карточки и текст Bootstrap меняются вместе с сайтом.

Выбор темы:

1. `assets/js/theme-init.js` подключается в `head` и сразу смотрит `localStorage` ключ `dr_theme`.
2. Если выбора ещё нет, смотрит `prefers-color-scheme: dark`.
3. Через `document.write` подключает нужный CSS-файл до первой отрисовки, чтобы страница не мигала светлой темой.
4. Кнопка «Тёмная тема» / «Светлая тема» в шапке вызывает `applyTheme()` из `assets/js/theme.js` и запоминает выбор.
5. Если человек ещё не нажимал кнопку, смена системной темы подхватывается. После ручного выбора система больше не перебивает его.

Кнопка имеет `aria-pressed` и `aria-label`, чтобы переключатель был понятен и без взгляда на цвет.

## Как открыть

Live Server на `index.html` в этой папке. Кнопка темы в шапке. Чтобы снова следовать системе, в DevTools → Application → Local Storage удалить ключ `dr_theme` и обновить страницу.

## Проверка

В браузере кнопка меняет подпись на «Светлая тема», фон становится тёмным, текст светлым, иконки и карточки остаются читаемыми. Подсказка в поле города и серое предупреждение о невыбранном городе тоже перекрашены через переменные, иначе на тёмном фоне они пропадали.

| Проверка | Результат |
| --- | --- |
| Светлая тема по умолчанию при светлой системе | Заложено в `theme-init.js` |
| Тёмная тема по `prefers-color-scheme` | Заложено, если в `localStorage` нет ключа |
| Кнопка переключает тему и пишет `dr_theme` | Проверено: подпись стала «Светлая тема», фон потемнел |
| После перезагрузки выбор сохраняется | Через `localStorage`, показать на защите |
| Контраст кнопок в тёмной теме | Терракота оставлена достаточно тёмной для белого текста |
| Описание блюда в карточке | Цвет берётся из `--ink`. Bootstrap сам ставил карточкам `#212529`, из-за этого текст оставался тёмным |
