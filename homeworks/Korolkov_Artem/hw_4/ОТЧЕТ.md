## Задание

Вынести используемые SVG-иконки в один спрайт. Если отдельных SVG раньше не было, добавить 3–5 иконок и собрать их в спрайт.

На сайте были не SVG, а эмодзи: книга в шапке и заглушка фото. Поэтому добавлены пять своих иконок и собраны в один файл.

## Что сделано

Файл спрайта: `assets/img/sprite.svg`.

Внутри пять символов `<symbol>`:

| id | Где используется |
| --- | --- |
| `book` | логотип, пункт «Главная», заглушка фото |
| `search` | пункт «Поиск» и заголовок страницы поиска |
| `user` | пункт «Личный кабинет» и заголовок кабинета |
| `heart` | кнопка «В избранное», рисуется из `app.js` |
| `sun` | заголовок «Меню на сегодня» |

На странице иконка не копируется целиком. Стоит короткая ссылка:

```html
<svg class="icon" aria-hidden="true" focusable="false">
  <use href="assets/img/sprite.svg#book"></use>
</svg>
```

Класс `.icon` в `styles.css` задаёт размер, `stroke: currentColor` и пустую заливку. Цвет иконки совпадает с цветом текста, поэтому в тёмной теме она сама становится светлой. Отдельный файл иконки для тёмной темы не нужен.

Иконки декоративные: рядом есть текст. Поэтому у `<svg>` стоит `aria-hidden="true"`. Скринридер читает «Поиск», а не «картинка лупа, поиск».

Кнопка избранного собирается в JavaScript функцией `createIcon("heart")`, потому что её текст меняется. Там же продублирован старый атрибут `xlink:href` на случай более старого браузера.

## Как открыть

Только через Live Server или другой локальный сервер. Внешний спрайт через `<use href="файл.svg#id">` браузер не загрузит со схемы `file://`.

## Проверка

На главной в шапке видны иконки книги, лупы, человека и солнца. Они нарисованы из одного файла. В консоли при открытии страницы ошибок не было. В тёмной теме иконки остаются видимыми, потому что обводка берётся из `currentColor`. Lighthouse Accessibility для этой главной страницы дал 100 баллов: спрайт не сломал имена кнопок и ссылок.

Погодные эмодзи в карточке прогноза не переносились в спрайт: это не прежние иконки интерфейса, а значки состояния погоды из `weather.js`. Пять интерфейсных иконок закрывают требование задания.
